# Archived: Dataverse for Teams plan

These guides described building the app by hand on Dataverse for Teams. That plan was dropped because **Microsoft is retiring Dataverse for Teams** (no new environments from 15 Nov 2026; existing ones decommissioned 30 Oct 2027).

The current edition stores data in SharePoint lists and builds the app automatically: see [../../README.md](../../README.md).

The UI spec (`02b-ui-design.md`) is kept for reference; its design is now implemented by the generator in `installer/app/`.
